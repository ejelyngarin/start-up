## Member profile information
Each profile includes the available information supplied in the latest individual portfolio forms: full name, preferred display name, introduction, biography, education, skills, languages, experience and activities, achievements, projects, interests, career goals, contribution, and public professional links.

Ejelyn's page includes both:
- Professional portfolio: https://www.ejelyngarin.work.gd
- Substack: https://substack.com/@jenpreferstoyou/posts

Blank or incomplete fields are omitted. Private phone numbers, personal contact details, and home addresses are not published.

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Use the Live Server extension and open `index.html`.
4. Test all navigation, member pages, and external links.

You can also open `index.html` directly in a browser for a basic local preview.

## Publish
This is a static website. Upload the contents of this folder to your static hosting provider (for example, GitHub Pages or another static host). Configure your domain separately with your hosting provider.

## Editing
- Profile content: `assets/js/profiles.js`
- Shared interactions and rendering: `assets/js/main.js`
- Styles: `assets/css/style.css`
- Images: `assets/images/`
- Content overview: `content-manifest.json`

Before publishing publicly, ask each member to review their profile and approve the displayed content and photo.
